5) Ctrl+c
If you run for example 'sleep 10' and press Ctrl+c in 10 seconds, command will terminate.
Ctrl+c will not terminate mysh


WHAT DOES NOT WORK:
1) Multiple pipes:

=======================================================================================================
mysh> ls | sort | head
mysh: only one pipe is supported
mysh>
=======================================================================================================

2) maximum arguments are limited to 64 in mysh.h
#define MAX_ARGS 64

WHY CD HAD TO BE BUILT-IN:
Because for external commands mysh creates child process, and it will change child directory
and parent direcoty 'mysh' will be unchagned, here is what would happen if 'cd' were external:

1) shell forks child process
2) child process runs /bin/cd 'foldername'
3) child will make system call 'chdir'
4) child process changes its own directory
5) child process finishes and exits
6) control returns to parent process and direcoty will be unchanged
